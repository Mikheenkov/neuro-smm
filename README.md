# Neuro SMM

Агент, который адаптирует посты из Telegram-канала под MAX, VK, Facebook и Threads (позже Stories и Instagram) и публикует их через час после поста. Архитектура — [docs/architecture.md](docs/architecture.md).

## Что уже есть

| Модуль | Что делает |
|---|---|
| `smm/ir.py` | Пост Telegram (текст + entities в UTF-16) → внутреннее представление с метками ссылок `L1…Ln` |
| `smm/links.py` | Нормализация, классификация ссылок (свой/чужой TG-пост, Meta, заблокированные в РФ…) и решение по каждой сети |
| `smm/filters.py` | Отсев рекламы (erid, «Реклама») и тем VPN до вызова модели |
| `smm/invariants.py` | Проверка фактов: числа, даты и названия из исходника должны дожить до версии |
| `smm/render.py` | Версия → HTML для MAX, текст для VK/FB/Threads; URL подставляются только здесь |
| `smm/validators.py` | Лимиты и правила каждой сети |
| `smm/llm/` | Claude через Anthropic API, схемы ответов, сборка промптов из `prompts/` |
| `smm/adapt.py` | Конвейер: фильтры → редактор → проверки → перегенерация → судья |
| `prompts/` | Голос автора, правила ссылок и площадок — редактируются как обычный текст |
| `smm/daemon.py` | Демон: слушает канал, карточка с кнопками на каждый пост, публикация по команде автора, отчёт |
| `smm/publishers/` | Threads API и MAX Bot API |
| `smm/setup_meta.py`, `smm/setup_max.py` | Получение токенов Threads и ID канала MAX в `.env` |

## Запуск

```bash
uv sync
uv run pytest
cp .env.example .env   # вписать ANTHROPIC_API_KEY
uv run python -m smm.dryrun --text "Текст поста"
```

Демон (публикует по-настоящему):

```bash
uv run python -m smm.daemon
```

Публикация — по команде: на каждый новый пост бот присылает карточку с кнопками «Опубликовать» и «Как будет выглядеть». Ещё команды в личке бота: `/post <номер>`, `/retry <номер> [сеть]`, `/status`, `/stop`, `/start`. Пересланный из канала пост — та же карточка; любой другой текст — пробная адаптация без публикации.

`dryrun` показывает версии для всех включённых сетей, решения по ссылкам, замечания судьи и стоимость, ничего не публикуя.
